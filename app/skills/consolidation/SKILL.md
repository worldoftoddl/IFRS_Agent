## 연결재무제표 작성 절차

### Step 1. 투자제거 분개 & 영업권/염가매수차익

1. 이전대가(취득가액) 확인
2. 비지배지분 측정 (공정가치법 또는 순자산 비례법)
3. 피취득자 식별가능 순자산 공정가치 산정
4. 영업권 = 이전대가 + 비지배지분 − 순자산 공정가치

### Step 2. 내부거래 제거

**하향판매** (지배기업 → 종속기업):
- 미실현이익 **전액 지배기업 귀속**
- 비지배지분에 배분하지 않음

**상향판매** (종속기업 → 지배기업):
- 미실현이익을 **지배지분:비지배지분 비율로 배분**
- 예: 60:40 지분율이면 미실현이익도 60:40 배분

**내부거래 유형별 처리:**

| 유형 | 미실현이익 | 과대감가상각 환입 | 순 미실현 |
|------|-----------|-----------------|----------|
| 재고자산 | 내부이익 × 미판매비율 | — | 미실현이익 |
| 유형자산 (비품, 차량 등) | 내부 처분이익 | 과대 감가상각비 = (내부가 − 연결장부가) ÷ 잔여내용연수 × 경과기간 | 처분이익 − 과대감가상각 환입 |

### Step 3. 지배기업 귀속 당기순이익

| 항목 | 산식 |
|------|------|
| 지배기업 개별 당기순이익 | A |
| ± 하향판매 내부거래 조정 | B (전액 지배) |
| + 종속기업 조정 당기순이익 × 지배지분율 | C |
| = 지배기업 귀속 연결 당기순이익 | A + B + C |

### Step 4. 비지배지분 귀속 당기순이익

| 항목 | 산식 |
|------|------|
| 종속기업 개별 당기순이익 | D |
| ± 상향판매 내부거래 조정 | E |
| = 종속기업 조정 당기순이익 | D + E |
| × 비지배지분율 | = 비지배지분 귀속 당기순이익 |

### Step 5. 비지배지분 잔액 (기말)

취득일 비지배지분
+ 비지배지분 귀속 당기순이익 (누적)
+ 비지배지분 귀속 기타포괄손익 (누적)
− 비지배지분 귀속 배당금 (누적)

### Step 6. 검증 (필수)

- [ ] 연결 당기순이익 = 지배기업 귀속 + 비지배지분 귀속
- [ ] 연결 자본 = 지배기업 귀속 자본 + 비지배지분
- [ ] 모든 중간 계산에 `verify_arithmetic` 도구 사용
- [ ] 검증 결과가 불일치하면 "✓" 표기 금지 — 오류를 명시하고 재계산
