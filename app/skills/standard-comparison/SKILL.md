## 기준서 비교 절차

### 1. 적용 범위 비교
- 각 기준서의 적용 범위(scope) 확인
- 중복 또는 배타적 영역 식별
- 어떤 거래에 어느 기준서가 우선 적용되는지 판단

### 2. 인식 기준 비교
- 자산/부채/수익/비용의 인식 조건 대조
- 인식 시점의 차이 식별

### 3. 측정 방법 비교
- 최초 측정 (원가, 공정가치 등)
- 후속 측정 (상각후원가, 공정가치, 재평가 등)
- 감액/손상 접근법 차이

### 4. 공시 요구사항 비교
- 각 기준서의 필수 공시 항목 대조
- 추가 공시가 필요한 영역 식별

### 5. 실무 영향 분석
- 재무제표에 미치는 영향 차이
- 전환 시 고려사항

### 비교 결과 제시 형식
비교 결과는 표 형식으로 정리하여, 각 관점(인식/측정/공시)별 차이를 명확히 대조.
반드시 근거가 되는 기준서 문단 번호를 인용.
