## 분개 생성 절차

### 1. 거래 분석
- 거래의 경제적 실질 파악
- 관련 당사자 및 역할 확인
- 적용되는 K-IFRS 기준서 식별

### 2. 계정과목 결정
- K-IFRS 정의에 맞는 자산/부채/자본/수익/비용 분류
- 계정과목명은 기준서 용어를 따름 (예: 사용권자산, 리스부채, 계약자산)

### 3. 차변/대변 구성
- 자산 증가 / 비용 발생 → 차변
- 부채 증가 / 수익 발생 / 자본 증가 → 대변
- 차변 합계 = 대변 합계 (대차 균형)

### 4. 금액 산정
- K-IFRS에서 요구하는 측정 기준 적용 (원가, 공정가치, 현재가치 등)
- 필요 시 계산 도구 활용 (현재가치, 유효이자율)

### 5. 검증 체크리스트
- [ ] 대차 균형 확인
- [ ] 계정과목이 K-IFRS 정의에 부합
- [ ] 측정 기준이 해당 기준서와 일치
- [ ] 최초 인식과 후속 측정 구분
- [ ] 관련 공시 요구사항 확인

### 분개 제시 형식
```
(차) 계정과목명    xxx원
    (대) 계정과목명    xxx원
```
각 계정과목에 대해 근거가 되는 K-IFRS 기준서 문단을 명시.
